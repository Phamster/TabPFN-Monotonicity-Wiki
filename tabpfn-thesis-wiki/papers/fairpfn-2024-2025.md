# FairPFN — fairness baked into the pretraining prior

The first (and so far primary) attempt to make a TabPFN-style model intrinsically fair rather than fair via pre/post-processing. The core idea: modify TabPFN's synthetic-prior generation process so that the random structural causal models (SCMs) used for pretraining explicitly include a *protected attribute* as an exogenous variable with a specified causal role. The network is then trained to predict the **counterfactually fair** outcome — i.e., what the prediction would be had the protected attribute taken a different value — directly from observational data, without needing the user to specify or discover the true causal graph for their own dataset.

This targets **counterfactual fairness** (an individual-level, causal notion — closely aligned with legal non-discrimination standards) rather than the more common group-fairness metrics (demographic parity, equalized odds). The 2024 version was Robertson's Master's thesis; the 2025 ICML version is the polished, peer-reviewed extension, reporting strong performance across both synthetic and real-world causal fairness scenarios without requiring the practitioner to know the causal model in advance.

## Relevance to thesis

This is the closest existing work to "constraint baked into a TFM's pretraining," which is structurally identical to what a monotonicity-constrained TFM would need to do — except for monotonicity instead of fairness. If you pursue a constraint-enforcement angle, FairPFN's prior-modification methodology is the template to adapt: instead of injecting protected-attribute causal structure into the synthetic SCM prior, you'd inject monotonic feature-output relationships. This is a strong methodological bridge between the fairness and monotonicity streams of this wiki, and a natural thing to cite as "shows the prior-modification approach works for one type of constraint; this thesis tests whether it generalizes to another."
